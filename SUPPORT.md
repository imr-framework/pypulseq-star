# Support

## Usage questions and discussions

Use GitHub Discussions for:

- installation and setup questions;
- PyPulseq-Star API questions;
- PyPulseq and Pulseq interoperability;
- gammaSTAR export and hierarchy questions;
- sequence-development discussions;
- requests for examples or documentation.

Discussions URL:

`https://github.com/imr-framework/pypulseq-star/discussions`

## Bug reports and feature requests

Use GitHub Issues for:

- reproducible software bugs;
- incorrect timing or validation behavior;
- plotting problems;
- writer or export issues;
- documentation errors;
- feature requests.

Issues URL:

`https://github.com/imr-framework/pypulseq-star/issues`

A useful bug report should include:

- PyPulseq-Star version or commit;
- Python version;
- operating system;
- PyPulseq version;
- Pulseq specification or interpreter version, if relevant;
- gammaSTAR version or environment, if relevant;
- a minimal reproducible example;
- the complete traceback or error output;
- expected and observed behavior.

## Security issues

Do not report suspected security vulnerabilities through public issues or
discussions. Follow `SECURITY.md`.

## Scanner and sequence-safety issues

For scanner execution or sequence-safety concerns, include:

- scanner vendor and model;
- software or interpreter version;
- field strength;
- gradient and RF limits used;
- generated `.seq` or `.seq.json` file, if it can be shared safely;
- timing-check output;
- scanner acceptance or rejection logs;
- whether the issue occurred in simulation, phantom testing, or another
  controlled environment.

Do not upload patient data, protected health information, credentials, or
proprietary vendor information.

## Support expectations

PyPulseq-Star is research software maintained on a best-effort basis. Response
times may vary. Commercial support and guaranteed response times are not
currently offered.
