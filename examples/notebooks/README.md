# PyPulseq-Star GRE notebook

`gre_relationship_aware_workflow.ipynb` is a six-section developer tutorial based on
`examples/demo_GRE.py`.

## Local use

From the repository root:

```bash
python -m pip install -e ".[plotting]"
jupyter lab examples/notebooks/gre_relationship_aware_workflow.ipynb
```

The notebook is structured for screenshots, talks, and later adaptation to Google Colab.
